Trang Chủ Trang Quản Lý Trang Debug

Trang Debug Code

1. Đoạn mã gốc bị lỗi (Theo yêu cầu):
function showGreeting() {
  let hour = new Date().getHours();
  let greeting = document.getelementbyid("23010001_txt_msg");
  if (hour < 12) {
    greeting.innertext = "Chào buổi sáng!";
  } else (hour < 18) {
    greeting.innertext = "Chào buổi chiều!";
  }
}
2. Kết quả chạy thử hàm đã sửa:
Tin nhắn hệ thống: [Đang tải...]
3. Giải thích các lỗi sai đã tìm thấy:
  • ❌ getelementbyid: Sai cú pháp camelCase. Sửa thành getElementById.
  • ❌ else (hour < 18): Lệnh else không được có điều kiện. Sửa thành else if (hour < 18).
  • ❌ innertext: Sai cú pháp DOM. Sửa thành innerText.
